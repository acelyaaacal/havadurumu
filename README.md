# 🪐 Hava Durumuu

A simple, modern, and user-friendly weather website
designed to make weather information easy to access.

🌐 **Live Website:** https://havadurumuu.com/

## About

Hava Durumuu is an independent weather website
that provides users with accessible weather
information through a clean and responsive interface.

## Features

- Weather information by city
- Responsive design for mobile and desktop
- Simple and user-friendly interface

## Technologies

- HTML5
- CSS3
- JavaScript
- Open-Meteo API
